PROJETO

===================================================================

// SOBRE O PROJETO


O Booklyn é um website desenvolvido para a divulgação de um
evento literário.

O projeto apresenta uma interface rústica, simples e organizada, com
informações sobre o evento, programação, atrações, galeria
de imagens e formas de contato, também possui animações e interatividade.

O site possui um contador regressivo desenvolvido em
JavaScript, que apresenta o tempo restante até a realização
do evento com base no contador feito na aula anteriormente.

===================================================================

// OBJETIVO


O objetivo do projeto é

O projeto busca proporcionar uma experiência visual simples,
agradável e fácil de utilizar.

===================================================================

// FUNCIONALIDADES E AFINS


- Página inicial com apresentação do Booklyn;
- Contador regressivo para o evento;
- Informações sobre o evento;
- Programação e atrações;
- Galeria de imagens;
- Informações sobre autores;
- Página de contato;
- Links para redes sociais;
- Efeitos visuais e interações;
- Layout responsivo;
- Navegação entre as páginas do projeto.

===================================================================

// TECNOLOGIAS UTILIZADAS


HTML5
Utilizado para criar a estrutura das páginas, organizando
textos, imagens, menus, botões e demais elementos do site.

CSS3
Utilizado para a estilização do projeto, incluindo cores,
fontes, espaçamentos, posicionamento dos elementos, efeitos
visuais e responsividade.

JavaScript
Utilizado para adicionar interatividade ao projeto,
principalmente no desenvolvimento do contador regressivo.

GitHub
Utilizado para armazenar e organizar os arquivos do projeto,
além de permitir o versionamento do código.

GitHub Pages
Utilizado para publicar o projeto e disponibilizá-lo para
acesso pela internet.

===================================================================

// ORGANIZAÇÃO DO PROJETO


O projeto possui seus arquivos organizados para facilitar o
desenvolvimento e a manutenção do website.

- index.html  → página inicial;
- pages/      → demais páginas do projeto em HTML;
- css/        → arquivos de css;
- js/         → arquivos JavaScript;
- assets/     → imagens e outros recursos utilizados no site.

===================================================================

// CONTADOR REGRESSIVO


Uma das principais funcionalidades do projeto é o contador
regressivo.

O contador foi desenvolvido utilizando JavaScript e apresenta
o tempo restante até o evento, permitindo que o usuário
acompanhe a aproximação da data.

===================================================================

// DATA DO EVENTO


09 de outubro de 2026, às 12h00.

===================================================================

// IDENTIDADE VISUAL


O projeto utiliza uma identidade visual inspirada no universo
literário, buscando transmitir uma aparência simples, elegante
e relacionada à proposta do Booklyn.

Foram utilizados elementos visuais, imagens, cards, botões e
efeitos de interação para melhorar a apresentação das
informações e a experiência do usuário.

===================================================================

// RESPONSIVIDADE


O site foi desenvolvido buscando proporcionar uma boa
visualização em diferentes tamanhos de tela.

A utilização de CSS permite adaptar a organização dos
elementos para diferentes dispositivos, contribuindo para uma
melhor experiência de navegação.
